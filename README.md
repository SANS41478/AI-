# AI嘉豪浓度测试

测测你是真懂 AI，还是懂装 AI。

一个玩梗向趣味测试：测量你的「AI 嘉豪浓度」——即 AI 火了就 FOMO、只懂皮毛却到处指点江山、爱用术语撑场面、被纠正还嘴硬的人。

## 特性

- **40 题题库池**：每次测试按 6 大行为模块分层抽样 25 题，每测题目不同
- **双轨计分**（MBTI 式）：
  - 浓度分 0~100%，5 档段位（AI 绝缘体 → AI 嘉豪本豪）
  - 四维类型（懂/装 · 藏/秀 · 稳/热 · 诚/吹），16 种类型档案
- **专业性机制**：分层抽样、动态满分归一化、交叉验证题对、置信度评估
- **可玩性机制**：嘉豪探测仪（模糊实时读数）、8 个隐藏成就、随机评语池、赛博扫描动画
- **分享卡片**：Canvas 原生生成检测报告图，一键保存 PNG
- 暗色赛博/终端风格，移动端优先

## 技术栈

Vue 3 + Vite + JavaScript（Composition API），零额外运行时依赖。

## 本地运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 生产构建
```

## 项目结构

```
src/
├── data/questions.js      # 40 题题库（嘉豪值 + 维度票 + 交叉验证标记）
├── data/results.js        # 段位/类型/成就/评语数据
├── composables/useQuiz.js # 抽样 + 双轨计分 + 交叉验证 + 成就判定
└── components/
    ├── HomePage.vue       # 首页
    ├── QuizPage.vue       # 答题页（探测仪 + 进度）
    ├── ResultPage.vue     # 结果页（扫描动画 + 维度条 + 成就）
    └── ShareCard.vue      # Canvas 分享卡片
```

完整策略设计见 `策略设计.md`。
